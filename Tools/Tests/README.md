# Проверки Tools

Запуск из папки Tools (Windows PowerShell 5.1 и Node.js):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Tests\Run-Regression.ps1
```

Для дополнительной проверки в PowerShell 7:

```powershell
pwsh -NoProfile -File .\Tests\Run-Regression.ps1
```

Тесты используют временные синтетические миссии и таблицы, подменённые HTTP-запросы и DOM. Они не запускают сервер и не читают рабочие `catalog_new_prefabs.json`, `legacy_refs_report.json` или `remap_table.json`. Для PowerShell не нужны дополнительные модули, для JavaScript используются встроенные библиотеки Node.js.

`core-regression.ps1` отдельно проверяет сканер старых миссий: незаданный корень отвергается с ошибкой вместо пустого результата, сухой прогон не трогает ни таблицу, ни отчёт, повторный прогон ничего не дублирует, а правка таблицы помечает отчёт устаревшим.

`ranking-regression.ps1` проверяет роли и сокращения, масштаб групп, совместимость, признаки техники, сортировку, старый формат каталога, сброс кэша и ответы ИИ. `editor-regression.cjs` и `index-regression.cjs` проверяют оба интерфейса: объяснения оценок, ручные альтернативы, явное применение рекомендации и защиту от устаревших ответов.

Признаки `matchingFeatures` версии 2 вычисляются из пути и имени. Они не подтверждают фактический состав группы или содержимое `.et`. Уровень соответствия — оценка по правилам, а не вероятность правильной замены.
